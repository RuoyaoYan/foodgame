# 寻味之旅 · 网页原型 v0.1

用来验证核心循环的最小可玩版本：**挂机攒金币 → 解锁城市 → 集市买食材/菜谱 → 厨房自由组合猜配方 → 手帐图鉴（永久增加每秒金币）**。

## 怎么玩
直接双击 `index.html` 用浏览器打开即可，不需要安装任何东西。
- 网址后加 `?debug`（如 `index.html?debug`）会出现 “+5000 金币” 调试按钮，方便快速测试。
- 存档保存在浏览器本地；关掉页面期间也会按现实时间累计金币（上限可配置）。

## 改数值
所有数值都在 `data/game.js`：城市解锁价、食材价格、菜谱配方、提示文案、菜谱价格、每道菜增加的金币/秒、初始金币、离线收益上限。
等号后面是标准 JSON，将来迁移 Godot 时可直接复制成 `game.json`。

## 本版范围（已与策划确认）
- 城市：成都（初始）、北京（2000）、罗马（8000）
- 菜品：麻婆豆腐、回锅肉、炸酱面、京酱肉丝、卡邦尼意面、黑胡椒奶酪面
- 各城市解锁的食材可以混合使用
- 做菜 = 自由组合猜配方（手帐给一句提示，也可花金币买菜谱看完整配方）
- 做错零惩罚：食材全部退回，并给出“少了点什么 / 有多余食材”的提示
- 食材按份购买，做菜成功时消耗
- 暂不做：风味罗盘、控火 QTE、正式美术（目前用 emoji 占位）

## 文件
- `index.html` / `style.css` / `game.js` — 游戏本体
- `data/game.js` — 游戏数据
