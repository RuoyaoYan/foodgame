# 吃

一款融合“放置经营”“食材探索”与“猜配方”的休闲图鉴收集游戏。本仓库目前是 **网页原型 v0.13（水彩手帐风；我的家 / 农场 / 厨房 / 店铺 / 商店街；13 个国家关卡 · 223 道料理 · 39 本主题食谱书；五大类食材全部进图鉴）**，用来验证核心循环；正式版计划用 Godot 制作并在 Steam 发行。

## 一、当前原型（已实现）

### 核心循环
**农场持续产出 / 商店街食品街进货原材料 → 厨房选做法猜出加工品与料理 → 店铺货架自动卖菜赚金币 → 开通新城市、五金店解锁新做法/新农场/新店、买家具**

界面底部是导航栏：🏠 我的家 · 🌾 农场 · 🍳 厨房 · 🏪 店铺 · 🏮 商店街 · 🗺️ 地图 · ⚙️ 设置。

### 画风：水彩 + 描边手帐风
- 纸张纹理背景、横线手帐页、手绘抖动的深棕描边（SVG 滤镜实现）。
- 卡片像贴在手帐上的纸片，顶部有和纸胶带，略微倾斜。
- 食材和料理显示为“水彩贴纸”：水彩晕染底色 + 白边 + 棕色描边。
- 世界地图为水彩晕染的海洋与陆地，配手绘指南针；底部导航是一排水彩书签；开始界面有水彩泼溅。
- 字体：大标题“吃”用毛笔字（只加载这一个字），其余文字用电脑自带的楷体，不依赖网络、不会缺字。

### 图片接入
- 食材图（含加工品）放 `images/ingredients/<食材id>.png`，料理图放 `images/dishes/<料理id>.png`，刷新即自动替换 emoji。
- 详细 id 列表见 [`images/README.md`](images/README.md)。

### 开始界面
- 大字标题“吃”，背景飘落食物，“开始旅程 / 继续旅程”按钮。
- 有存档时显示进度概况（图鉴收集数、到过的国家、金币），并提供“重新开始”（点两次确认）。
- 游戏中点左上角“吃”可回到开始界面。

### ⚙️ 设置（底部导航单独一项）
**语言**（简体中文 / 日本語，开始界面也能切；切换会刷新页面，存档不受影响）、背景音乐 / 音效开关（素材尚未加入，先记住选择）、**开发者模式**（金钱无限 ∞、图鉴全部可见、商店街什么都能买、做法全部可用）、回到开始界面、重置存档（点两次确认）、关于。

### ⭐ 料理熟练度
- 每做出 1 份料理（下锅或一键出餐）熟练度 +1 点。
- 等级：Lv.1（0 点）→ Lv.2（5）→ Lv.3（15）→ Lv.4（30）→ Lv.5（50，满级）。
- 每升一级，这道料理的售价 +10%（Lv.5 为 +40%）。数值在 `data/game.js` 的 `mastery` 里。

### 2. 🌾 农场（参考《洋果子店》）
- 每块地**选一次**种 / 养什么，之后**持续产出**原材料（关掉页面也会产），产出攒在地里，满了就停，点“收取”或“一键收取”放进仓库。可以随时换种 / 换养。
- **升级**地块（Lv.1 → Lv.5，🪙150 / 400 / 1000 / 2500）：每级产出速度 +50%，能攒的上限 +5 份。
- **扩建**：在商店街的**五金店**买新农场——菜地 2 → 5 块（🪙300 / 1000 / 3000），畜栏 2 → 5 个（🪙400 / 1200 / 3500）。
- **受城市限制**：开通对应国家后才能种养。

### 3. 🍳 厨房
- **商店街和农场只有原材料**；豆腐、酱、面这类加工品要在厨房里自己做。
- 把食材放进锅里，再在锅边选一个**食材制作方式**，点“下锅！”。共 7 种：

| 做法 | 解锁 |
|---|---|
| 🔪 直接加工 | 开局就有 |
| 🔥 烤焗煎煮 | 开局就有 |
| 🫙 发酵 | 五金店 🪙300 |
| ♨️ 蒸焖 | 五金店 🪙500 |
| 🍤 油炸 | 五金店 🪙800 |
| 🥤 做成饮料 | 五金店 🪙1200 |
| ❄️ 冷冻 | 五金店 🪙1500 |

- **加工品和料理都要自己猜**：食材组合 + 做法都对才成功。加工品每次产 1–2 份进背包；料理产 1 份成菜，可拿去店铺卖。
- **零惩罚**：猜错时食材全部退回，并给温馨提示——“食材对了但做法不对”、“好像少了点什么”、“有的食材是多余的”或“同一种食材放一份就够”。
- **📖 查看食谱书**：锅旁边的按钮，打开已拥有食谱书里的全部配方，可**搜索**（料理名、食材、做法、城市）；点“放进锅里”自动放好食材并选好做法，缺的食材会提示。
- **已会做的**：研发过的加工品和料理可以一键做（做 1 次 / 全做），缺的食材标红。

### 🌐 多语言（简体中文 / 日本語）
- 在“设置 → Language / 语言 / 言語”或开始界面底部切换。选择记在浏览器里（`localStorage` 的 `xunwei_lang`），第一次打开时日语浏览器会默认日语。
- **界面文字**：`game.js` 里所有文字都写成 `T("中文原文 {0}", 参数)`——中文原文就是 key，中文模式原样输出，日语模式去 `data/ja.js` 的 `ui` 词典里查，查不到就退回中文。`index.html` 里的固定文字由 `i18n.js` 在加载时按同一本词典替换。
- **游戏数据**（食材、料理、城市、成就、家具……的名称与说明）：`data/ja.js` 的 `data` 部分按 id 写日语，加载时覆盖到 `GAME_DATA` 上，所以改数值仍然只动 `data/game.js`。
- **新增食材 / 料理 / 成就时**：在 `data/game.js` 加中文，再到 `data/ja.js` 的 `data` 里按同样的 id 补一行日语；没补的会先显示中文。
- **检查有没有漏翻的界面文字**：网址后加 `?i18n`，日语模式下缺的 key 会打印在浏览器控制台（`[i18n] 缺少翻译`）。
- 想加第三种语言：在 `i18n.js` 的 `LANGS` 里加一项，照 `data/ja.js` 的格式写一个词典文件。

### 🚀 流畅度
- **界面刷新**：每秒刷新的页面（农场、店铺、商店街、地图）只在 HTML 真的变了的时候才重写 DOM，食品街一次 150 多张卡片不再每秒整片重建。
- **绘制**：整页纸张、每张卡片、每个贴纸上的 SVG 位移滤镜去掉了（小件按钮、标签、弹窗、导航保留手绘抖动）；贴纸 emoji 的描边从 9 层阴影减到 2 层；纸张纹理改放固定定位的伪元素，滚动不再重绘。
- **主循环**：由每帧一次改为每 0.25 秒一次，页面在后台时不运行；店铺和农场本来就按时间戳结算，不依赖帧率，切回来会立刻补算。
- **加载**：图片预加载放到空闲时间分批、低优先级；毛笔字体不再阻塞首屏；搜索框加了输入防抖；新增 `sw.js`（Service Worker），第二次打开几乎瞬间加载，断网也能玩。
- 实测（开发者模式、停在食品街 5 秒）：主线程耗时从约 345 ms 降到约 18 ms。
- 说明：游戏是纯单机前端，存档在浏览器里，所以没有加服务器后端；如果以后要做云存档 / 排行榜，再单独接。

## 二、原始策划文档

> 以下为策划 PDF 原文整理（原项目名《寻味之旅》，现已更名为“吃”）。

### 一、项目概述 (Project Overview)
《寻味之旅》是一款融合了“放置挂机”、“食材探索”与“调味解谜”的休闲图鉴收集游戏。玩家将游历大江南北，在各地集市采购最基础的原子食材，通过独特的“风味罗盘”系统还原出经典地方名菜，最终填满一本充满人间烟火气的美食手帐。

- **商业模式**：Steam 平台纯买断制（无内购、无广告、无版号限制）。
- **受众群体**：喜爱《洋果子店》、《潜水员戴夫》、星露谷物语等画风治愈、节奏舒缓、有强收集癖的休闲玩家。

### 二、技术与发行架构 (Technical Architecture)
| 模块 | 技术选型 / 方案 | 优势与原因 |
|---|---|---|
| 游戏引擎 | Godot Engine | 极其轻量，极度擅长 2D UI 交互；完美支持 MacBook 开发；一键打包 Windows .exe 以供 Steam 发行 |
| 数据管理 | JSON 文件驱动 | 食材属性、菜谱配方全部表格化。产品经理可以直接修改文本调整游戏数值，无需修改代码。 |
| 发行平台 | Steam (PC 端) | 避开国内 App Store 严苛的版号审查与内购限制，直接面向全球核心独立游戏玩家变现。 |
| 美术生产 | ChatGPT | |

### 三、核心玩法循环 (Core Gameplay Loop)
游戏采用“无挫败感”的治愈系设计，核心循环分为三个无缝衔接的阶段：

**1. 放置赚取【金币】与大地图探索**
- 挂机印钞：游戏时间与现实同步。已解锁的图鉴等级越高，每秒自动产出的【金币】就越多（例如：+15 金币/秒）。
- 城市解锁：消耗大量金币解锁新的大地图节点（如：花费 5000 金币解锁“北京”航线）。
- 本地集市：在已解锁城市的集市里，使用少量金币“进货”当地特有的原子食材（如成都的汉源花椒、郫县豆瓣酱）。

**2. 厨房研发：“风味罗盘”与“治愈控火”**
- 风味罗盘（调味）：界面左侧为巨大的十字坐标轴（横轴：咸-甜，纵轴：酸-辣）。玩家将背包中的基础食材拖入锅中，指针会产生带有物理阻尼感的平滑移动。目标是将指针调和至隐藏的“目标风味区间”。
- 控火 QTE（烹饪）：按住屏幕中央的铁锅，温度条上涨。在宽广的“绿色黄金区间”松手即可完美出锅。
- 零惩罚机制：如果调味偏离或火候不对，只会收到温馨提示，并且 100% 退还所有食材。拒绝压力！

**3. 手帐图鉴记录**
- 研发成功后，伴随平滑的 3D 翻书动画，解锁精美的 AI 水彩手绘风插画。
- 图鉴中包含料理的历史渊源、文化科普，并永久增加全局的金币秒收益。

## 四、开发说明

### 本地运行
直接双击 `index.html` 用浏览器打开，无需安装任何东西。
- 网址后加 `?debug`（如 `index.html?debug`），在“我的家 → 设置”里会出现调试按钮：“+5000 金币”和“时间快进 5 分钟”。
- “我的家 → 设置 → 开发者模式”打开后：金钱无限、图鉴全部可见、食品街全部食材可买、做法全部可用。
- “我的家 → 设置 → 重置存档”点两次可清空进度。

### 修改数值
所有数值都在 `data/game.js`：初始金币、离线结算上限、货架数量/容量/售卖间隔/扩建价格、城市开通价与经纬度、食材分类、做法、原材料（城市/价格）、加工品与料理配方（原料/做法/产量/提示）、菜谱价格、售价、农场（地块数/扩建/升级价格、每级加成、产出速度）、家具（价格/加成/房间位置）。
等号后面是标准 JSON，迁移 Godot 时可原样复制为 `game.json`。

### 文件结构
| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构（开始界面 + 我的家/农场/厨房/店铺/商店街/地图 + 底部导航） |
| `i18n.js` | 多语言：`T()` 翻译函数、语言切换、把日语数据覆盖到 `GAME_DATA` |
| `data/ja.js` | 日语词典（界面文字 + 食材 / 料理 / 城市 / 成就等名称），只在日语模式下加载 |
| `sw.js` | 离线缓存（Service Worker） |
| `style.css` | 治愈系手帐风样式 |
| `game.js` | 游戏逻辑：存档与离线结算、我的家、农场、厨房、店铺、商店街、地图 |
| `worldmap.js` | 手绘风世界地图（简化大陆轮廓 + 城市图钉 + 航线） |
| `data/game.js` | 游戏数据（JSON） |
| `images/` | 食材与料理图片（按 id 命名） |

### 部署
网站通过 GitHub Pages 从 `gh-pages` 分支发布。开发在 `main` 上进行，发布时执行：
```bash
git push origin main:gh-pages
```
约 1 分钟后网址自动更新。（也可以在 Settings → Pages 把来源改成 `main` 分支，之后只推 `main` 即可。）
